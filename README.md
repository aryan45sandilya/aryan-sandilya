## Selected projects

### [CodeReview.ai](https://github.com/aryan45sandilya/CodeReview.ai)
A GitHub App that reviews pull requests automatically. It receives PR webhooks, fetches the diff, and posts severity-ranked inline review comments generated by an LLM, plus an email summary. A BullMQ + Redis queue separates the webhook acknowledgement from the review work, so PRs across repos are processed in parallel.

`Next.js` `TypeScript` `Node.js` `BullMQ` `Redis` `Octokit` `NextAuth` `Groq API` `Nodemailer`

### [AI Receptionist](https://github.com/aryan45sandilya/AI-Receptionist)
A voice agent that answers a small business's phone, checks real availability, books, moves or cancels appointments, and hands off to a human when asked. Streaming speech-to-text, a tool-using LLM loop, and text-to-speech with barge-in. Double bookings are blocked by a Postgres exclusion constraint, and the model books by slot ID so it can't invent a time.

`Python` `FastAPI` `SQLAlchemy` `Alembic` `PostgreSQL (Supabase)` `Twilio` `Deepgram` `React` `TypeScript`

### [Urban Heat & Energy Intelligence Engine](https://github.com/aryan45sandilya/Urban-Heat-Energy-Intelligence-Engine)
Predicts urban heat-island intensity and energy demand from public weather-station, OpenStreetMap, and grid-load data. It explains each prediction with SHAP and includes a what-if simulator and a hotspot map. A reproducible ML pipeline compares several model families before serving the selected model through FastAPI.

`Python` `scikit-learn` `SHAP` `pandas` `FastAPI` `Next.js` `TypeScript` `Docker` `GitHub Actions`

### [InterviewAI](https://github.com/aryan45sandilya/InterviewAI)
A mock interview platform. You answer AI-generated questions by voice, each answer is transcribed and scored, and there's a live coding round with in-browser code execution, resume-based interviews, and per-question reports.

`Next.js 15` `TypeScript` `PostgreSQL (Neon)` `Drizzle ORM` `Clerk` `Gemini & OpenAI APIs` `Monaco Editor` `Judge0`
